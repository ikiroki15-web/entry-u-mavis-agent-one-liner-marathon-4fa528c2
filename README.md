# One-Liner Marathon

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the make.fun One-Liner Marathon bounty: a program that writes a
single one-line comedy joke (107 characters) to `/output/entry.txt`.

The joke: "I asked my AI assistant for motivation, so it scheduled a meeting
with myself and declined it on my behalf."

## Run

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (UTF-8, one line, within the 1–280
character gate). No dependencies, no network.
